시스템 목적

뉴스/공시 기반 시초가 매매 전략을 백테스트하고 A/B/C/C+/D 5가지 전략의 성과를 비교 분석합니다. BNF와 cis 등 일본의 전설적 트레이더의 투자법을 참고하여 설계되었습니다.

데이터 소스

  • DART: 금융감독원 전자공시 시스템
  • 네이버: 네이버 금융 뉴스
  • 주가: pykrx / FinanceDataReader

전략 구성 (5가지)

  • 전략 A: 기본 필터링 (시총, 거래량, 키워드)
  • 전략 B: 고급 필터링 (급등주/고가 제외)
  • 전략 C: 기술적 분석 (RSI, MA, 수급)
  • 전략 C+: C 강화 (거래량 모멘텀, 볼린저밴드)
  • 전략 D: BNF/cis 하이브리드 (괴리율, 양봉)

매매 방식

  • 매수: 장 시작 시초가 매수
  • 매도: 당일 종가 매도 (데이트레이딩)
  • 목표: 일일 수익률 극대화

공통 필터 (A, B, C, C+, D 모두 적용)

최소 시가총액500억 원소형주 제외
최대 시가총액10조 원대형주 제외
최소 평균 거래량10만 주유동성 확보
최소 키워드 점수1점호재 뉴스 필터

주요 모듈 설명

Collectors

외부 데이터 소스에서 공시, 뉴스, 주가 데이터를 수집합니다. price_collector는 BNF/cis식 기술적 지표(25일 괴리율, 양봉, 거래량 모멘텀)를 계산합니다.

Analyzers

수집된 데이터를 분석하여 매수 시그널을 생성합니다. stock_filter는 5가지 전략(A/B/C/C+/D)을 적용합니다.

Scripts

전체 파이프라인을 실행하는 메인 스크립트입니다. 5가지 전략 결과를 모두 저장하고 비교합니다.

Workflows

GitHub Actions로 정해진 시간에 자동 실행됩니다. KST 08:30(스캔), 15:40(추적).

BNF/cis 투자법 참고 사항

BNF 스타일

역추세 전략: 25일 이동평균선 대비 괴리율을 분석하여 과매도 구간(-5%~)에서 반등을 노립니다. 단, 급락(-5% 미만)은 위험하므로 제외합니다.

cis 스타일

모멘텀 전략: "오르는 주식을 산다"는 원칙. 전일 양봉 + 거래량 급증 종목을 선별하여 상승 모멘텀에 편승합니다.

하이브리드 (D전략)

BNF의 괴리율 분석과 cis의 양봉/거래량 필터를 결합하여 "적정 구간에서 상승 시작하는 종목"을 포착합니다.

C+ 전략

기존 C전략에 cis식 거래량 모멘텀(150%+)과 볼린저밴드 위치(20~80%) 필터를 추가하여 신뢰도를 높였습니다.

면책 조항

이 시스템은 모의투자 및 학습 목적으로 제작되었으며, 실제 투자 조언이 아닙니다. 모든 투자 결정과 그에 따른 책임은 사용자 본인에게 있습니다. 과거 수익률이 미래 수익을 보장하지 않습니다.
